# CLAUDE.md

Public version of Carte: world map (D3 + canvas, Equal Earth) with live radio and TV per country,
favourites and visited countries. No notes, news or Telegram bot (those stay in the private
`carte_news` project). README.md is the user-facing doc (English), written for people who don't code.
- First visit = welcome assistant, then "⚙ Paramètres" (one dialog `#setup`: `#wiz` pages lang → intro →
  wants → connect → done, progress in localStorage `carte.wizard` so it resumes after an OAuth
  redirect; `#settings` = language, theme, music service, connection cards `#cards` moved between
  the two). Done flag `carte.onboarded`. Without the server, music parts are hidden (`.server-only`).
- Interface in fr / en / es / zh / ar (Arabic = `dir=rtl`): `web/i18n.js` (`tr(key, vars)`, `applyI18n()`,
  country names via `Intl.DisplayNames`), texts in `web/strings.js` (static ones marked `data-i18n*` in
  index.html). Server errors are raised in French and translated by `messages.py` + `messages.json`
  from the page's `X-Carte-Lang` header. `facts.json` holds French at the top level and the other
  languages under `i18n`. The zoom transform in app.js is called `t`: never name anything else `t`.

- Two modes, same `web/`: static (GitHub Pages, `.github/workflows/pages.yml` publishes `web/`;
  favourites + visited in localStorage) and local (`python3 server.py`, stdlib, 127.0.0.1:8765;
  state in `data/`, gitignored; music features on). The page detects the server with `GET /api/state`.
- Music (server only): `music.py` (ICY title, AudD clip, yt-dlp search, YouTube Data API), `spotify.py`
  (same function shapes for Spotify; routes pick it with `"service": "spotify"`; full-track playback = Web
  Playback SDK in the page, fed short-lived tokens by `/api/spotify/token`, embed extracts as fallback;
  Liked Songs = pseudo-playlist id `"liked"` (`GET /me/tracks`, `PUT/DELETE /me/library`), not movable/editable), `connect.py` (in-app
  "⚙ Paramètres" music accounts: keys stored in `~/.config/carte/` 600, OAuth with PKCE + one-time `state`;
  Google returns to `http://127.0.0.1:<port>/`, Spotify to `/oauth/spotify`). `tools/music_setup.py` is the
  terminal alternative. Server refuses foreign Host/Origin.
- Country id = Natural Earth `ADM0_A3`. `web/data/` is generated by `tools/build_map.py` and
  `tools/build_facts.py`. Radio = Radio Browser API, TV = Famelack data (jsDelivr + raw GitHub).
- No build step, no tests: check JS with `node --check web/app.js`; drive the page with REA /
  Playwright Chromium (`~/.cache/ms-playwright/chromium-*/chrome-linux64/chrome`, has Widevine).
